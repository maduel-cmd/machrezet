# מחרזת — משחק חרוזים

אפליקציית משחק ליצירת **צמידים**, **שרשראות** ו**קישוטים** מחרוזים (בהשראת Beadsmith Jen Tribal, Lucid Beads / beads.co, וערכות Fashion Angels).

ריפו עצמאי (לא חלק מ־TrailLink).

**אתר חי:** https://machrezet-beads.netlify.app

## מה יש בפנים

- מדף חרוזים עשיר: פוני, אותיות (עברית+אנגלית+ספרות), אבנים יקרות, פנינים, היישי, קריסטל, מתכת, עץ, קישוטים וזרעים
- **6 עולמות נושא** עם רקעים וקטוריים, חרוזים ותליונים מותאמים
- **יצירה חופשית** — השחלה חרוז־אחר־חרוז
- **אתגר העתקה** — מוצגת דוגמה, השחקן משחזר ומקבל ציון התאמה
- **אתגר בקשה** — תיאור מילולי + ניקוד לפי כללים
- **גלריה** — שמירה **לנצח** ב־`localStorage` במכשיר בלבד
- **PWA** — התקנה ומשחק לא מקוון

## הרצה

```bash
npm install
npm run dev
```

נפתח ב־`http://127.0.0.1:5180`.

## בדיקות ובנייה

```bash
npm test
npm run typecheck
npm run build
```

## פריסה (Netlify)

- `netlify.toml` מוכן בשורש
- Build: `npm run build` · Publish: `dist` · Node 22
- אחרי מעבר לריפו זה: לחבר מחדש את אתר Netlify (`machrezet-beads`) לריפו החדש
