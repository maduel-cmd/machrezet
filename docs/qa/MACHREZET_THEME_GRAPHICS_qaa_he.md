## צ׳ק־ליסט ידני (מובייל־ראשון / מיקה)

### A. בית + RTL
1. פתחו את האפליקציה.
2. **צפוי:** לוגו מחרזת, כרטיסי משחק בעברית, כיוון RTL, בורר עולם ב־topbar.

### B. עולמות רקע
1. לחצו על שבב העולם → בחרו «יער הפיות» / «גלקסיה» / «חוף פסטל».
2. **צפוי:** רקע וקטורי מתחלף; צבעי מגש/כפתורים משתנים; אחרי רענון — אותו עולם נשמר.

### C. יצירה + צ'ארמים
1. «בואו ניצור» → לשונית תליונים → גררו צ'ארם לחוט.
2. הוסיפו חרוזי פלטה → «סיימתי! לקשור».
3. **צפוי:** חגיגה/שמירה; היצירה בתיבה; חרוזים מוצקים על החוט.

### D. העתקה / משימה
1. דוגמאות להעתקה — השלימו דוגמה קצרה.
2. משימה קטנה — ענו לכלל אחד לפחות.
3. **צפוי:** ציון / שמירה בלי קריסה.

### E. תיבת תכשיטים + שיתוף
1. פתחו תיבה → פתיחה בעורך / ייצוא תמונה אם זמין.
2. **צפוי:** שמירות קיימות אחרי רענון; אין דרישת התחברות לענן.

### F. PWA בטלפון
1. כפתור עדכון / התקנה.
2. מצב לא מקוון בסיסי אחרי ביקור אחד.
3. **צפוי:** אייקון מחרזת; cache חדש (v6+) אחרי עדכון.
