# יעד נראות מחרזת + פרומפט לולאה

מסונתז מסיעור (Claude / GPT / Gemini / Grok / Cursor) + מחקר שוק (Lucid Beads, beads.co, אופטיקת כדורי זכוכית CSS: specular + rim + contact shadow; WebGL ליהלומים = overkill ל־MVP).

## יעד מיטבי (Definition of Done)

המשתמש רואה **חרוזים שנראים כמו חרוזים פיזיים** (לא עיגולי צבע שטוחים), וברור שהם **מושחלים על חוט רציף**:

1. **חומרים:** לכל קטגוריה שכבות אור ייחודיות — פוני מבריק־פלסטיק, אבן יקרה עם ברק פנימי, פנינה רכה, קריסטל פאסטות, אות קובייה עם שיפוע, היישי דק, מתכת עם שיקוף, עץ עם גרגיר, קישוט עם נפח.
2. **תאורה אחידה:** מקור אור עליון־שמאלי קבוע (specular ב־~30%/25%) על כל החרוזים — כמו תמונת סטודיו אחת, לא מדבקות.
3. **חור + חוט (חובה):** בכל חרוז נראה חור אופקי; החוט עובר **דרך** החרוזים ונגלה בין חרוז לחרוז ובתוך החור.
4. **עומק:** rim light פנימי, צל מגע קל, בלי emoji כתחליף לקישוט.
5. **מובייל RTL:** קריא ב־390px; אותיות קריאות; ניגודיות מספקת.
6. **ביצועים:** CSS/SVG בלבד (בלי Three.js ב־MVP).

## פרומפט לולאה (ביצוע → QA → תיקון)

```
אתה משפר את מחרזת עד עמידה ביעד הנראות למעלה.

לולאה:
1. IMPLEMENT — שפר BeadVisual + StrandPreview + CSS כך שחרוזים ריאליסטיים ומושחלים על חוט.
2. BUILD — npm run build && deploy Netlify.
3. QA (חובה):
   - צילום מסך עורך עם ≥5 סוגי חרוזים על החוט
   - מובייל ~390px
   - בדיקת קריטריונים: specular אחיד, חור נראה, חוט רציף דרך החרוזים, בלי emoji ★/♥ גולמי, אותיות קריאות
   - לפי כללי הזיכרון: גיבוי לפני שינוי, עברית RTL, computerUse לצילומים
4. אם נכשל קריטריון → FIX וחזור ל־2.
5. עצור רק כשכל קריטריוני היעד עוברים ב־QA.
```

## קונצנזוס סיעור AI (GPT / Gemini / Grok / Claude)

ארבעת הבריפים מסכימים על אותו ליבה:

1. **השחלה > חומר** — חוט שנכנס/יוצא מחור הוא מה שאומר «חרוז אמיתי»; גרדיאנט יפה לבד לא מספיק.
2. **תאורה אחידה** — מקור אור אחד (specular עליון־שמאלי) לכל הסצנה.
3. **חומרים נפרדים** — פוני ≠ פנינה ≠ מתכת ≠ עץ ≠ קריסטל (לא אותה נוסחה).
4. **MVP ב־CSS/SVG** — בלי WebGL בהתחלה; שדרוג ל־Three רק אם צריך סיבוב 3D חופשי.
5. **שלב הבא (Phase B, Claude+GPT)** — `StrandCanvas` ב־SVG אחד: path רציף לחוט, mask שמסתיר חוט מאחורי חרוז אטום, סיבוב לפי tangent, ואז `materials.ts`.

### מה כבר יושם (Phase A)
שכבות specular/rim, חור אליפטי עם צבע חוט, חוט רציף בין קלאספים, QA עבר ב־2026-08-26.

### Phase B (ביצוע)
- `materials.ts` — מרשם חומר לפי קטגוריה
- `BeadSvg.tsx` — ספרייט SVG עם חור cutout
- `StrandCanvas.tsx` — path רציף + sandwich (חוט אחורי → חרוז → מקטע קדמי בחור) + סיבוב לפי tangent + שקיעת עקומה לפי סוג מוצר

| סיבוב | ממצא QA | פעולה |
|------|---------|--------|
| 1 | FAIL: חורים לא ברורים / ברק חלש | שכבות specular + חור מצויר |

| 6 | PASS חוט דרך חורים (חוט שחור) | אושר ב־QA חי |
